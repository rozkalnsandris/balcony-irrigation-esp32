# Koda un konfigurācijas audits — 2026-08-16

## Pārbaudītie avoti

Audits balstīts uz aktuālo Espressif Arduino-ESP32 / ESP-IDF dokumentāciju, PlatformIO dokumentāciju, Home Assistant MQTT dokumentāciju, GitHub Actions drošības dokumentāciju un projekta izmantoto PubSubClient upstream release informāciju.

## Labojumi bootstrap laikā

1. **Laika joslas kļūda:** `setenv(TZ)` + `configTime(0, 0, ...)` bija loģiski pretrunīgi, jo Arduino-ESP32 `configTime()` pati pārraksta `TZ`. Pāriets uz `configTzTime(TZ_INFO, ...)`, lai CET/CEST noteikumi saglabātos pēc SNTP inicializācijas.
2. **PlatformIO/pioarduino pin:** pāriets no `55.03.39` uz `55.03.311` (Arduino 3.3.11 / ESP-IDF 5.5.5), kas auditēšanas datumā ir jaunākais stable pioarduino release.
3. **Build/OTA robeža:** noklusējuma vide ir `esp32_ci`; OTA atrodas atsevišķā `esp32_ota` vidē. OTA `--auth` netiek interpolēts parastajā projekta konfigurācijā — to apzināta upload laikā nodod ar PlatformIO oficiālo `PLATFORMIO_UPLOAD_FLAGS` vides mainīgo.
4. **OTA mērķis:** hard-coded `192.168.0.53` aizstāts ar firmware hostname `balkons-esp32.local`. PlatformIO atbalsta mDNS hostname kā `upload_port`.
5. **GPIO12 dokumentācija:** skaidri pierakstīts, ka GPIO12/MTDI ir ESP32 strapping pin un kāpēc gala montāžā priekšroka GPIO25.
6. **CI:** pievienots tikai kompilējošs GitHub Actions workflow. Tas neveic OTA, HA REST komandas vai sūkņa aktivizāciju.
7. **Reproducējams CI:** PlatformIO Core piesprausts pie stable `6.1.19`; GitHub Actions ir piespraustas pie pilniem commit SHA un workflow `GITHUB_TOKEN` ir tikai `contents: read`.

## Pārbaudīts un atstāts nemainīts

- PubSubClient `2.8.0` joprojām ir upstream jaunākais release un satur izmantotās `setBufferSize`, `setKeepAlive` un `setSocketTimeout` API.
- MQTT discovery saīsinātās atslēgas (`stat_t`, `cmd_t`, `uniq_id`, `avty_t`, `dev`) ir Home Assistant atbalstīta discovery forma.
- Retained discovery un retained availability ir derīga HA discovery stratēģija.
- ArduinoOTA `setPassword()` ir atbalstīts; aktuālajā Arduino-ESP32 tas paroli glabā kā SHA-256 hash un uploaderis atbalsta `--auth`.
- Task WDT inicializēšanas/reconfigure/add/reset pieeja atbilst ESP-IDF 5.x API modelim.

## Apzināti neatrisināts ar kodu

- Releja NO kontakta, flyback diodes un barošanas kondensatoru esamību nevar pierādīt no repo; tas ir fizisks verifikācijas uzdevums.
- GPIO12 → GPIO25 firmware maiņu nedrīkst izdarīt pirms fiziska vada pārlikšanas.
- HA `ON` pašreiz sāk sesiju līdz 180 s hard limitam. Tas nav mainīts bootstrap auditā, lai klusām nemainītu esošo vadības semantiku; ja vēlamies konservatīvāku HA pogas uzvedību, to jāmaina atsevišķā, skaidri testējamā izmaiņā.
