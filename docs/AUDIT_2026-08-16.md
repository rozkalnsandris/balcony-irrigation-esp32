## Labojumi bootstrap laikā

1. **Laika joslas kļūda:** `setenv(TZ)` + `configTime(0, 0, ...)` bija loģiski pretrunīgi, jo Arduino-ESP32 `configTime()` pati pārraksta `TZ`. Pāriets uz `configTzTime(TZ_INFO, ...)`, lai CET/CEST noteikumi saglabātos pēc SNTP inicializācijas.
2. **PlatformIO/pioarduino pin:** pāriets no `55.03.39` uz `55.03.311` (Arduino 3.3.11 / ESP-IDF 5.5.5), kas auditēšanas datumā bija izvēlētais stable pioarduino release.
3. **Build/OTA robeža:** noklusējuma vide ir `esp32_ci`; OTA atrodas atsevišķā `esp32_ota` vidē. OTA `--auth` netiek interpolēts parastajā projekta konfigurācijā — to apzināta upload laikā nodod ar PlatformIO `PLATFORMIO_UPLOAD_FLAGS` vides mainīgo.
4. **OTA mērķis:** hard-coded `192.168.0.53` aizstāts ar firmware hostname `balkons-esp32.local`.
5. **GPIO12 dokumentācija:** skaidri pierakstīts, ka GPIO12/MTDI ir ESP32 strapping pin un kāpēc gala montāžā priekšroka GPIO25.
6. **CI:** pievienots tikai kompilējošs GitHub Actions workflow. Tas neveic OTA, HA REST komandas vai sūkņa aktivizāciju.
7. **Reproducējams CI:** PlatformIO Core piesprausts pie `6.1.19`; GitHub Actions ir piespraustas pie pilniem commit SHA un workflow `GITHUB_TOKEN` ir tikai `contents: read`.
